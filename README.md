# Shyfoxie's Dream Studio ✨

A cozy, magical interactive visual art experience featuring continuous Diamond Painting, Falling Sand, and Bubble Pop Art with 100 designs across 10 curated themes for ambient streaming and relaxation.

## 🚀 GitHub Pages Deployment Guide

This project is fully pre-configured for GitHub Pages:

### Method 1: Automatic GitHub Actions (Recommended)
1. In your GitHub repository, navigate to **Settings** > **Pages** (in the left sidebar).
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. That's it! The pre-configured `.github/workflows/deploy.yml` will automatically build and deploy the app whenever you push to `main`.

### Method 2: Deploy from Branch (/docs folder)
1. In your GitHub repository, navigate to **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, keep **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and change the folder dropdown from `/ (root)` to **/docs**.
4. Click **Save**.

The site will now be live and fully functional at `https://destiniedesigns.github.io/ASMR/`!
